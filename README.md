# 🎬 Movie Recommendation System (Java)

A console-based **Movie Recommendation System** built in Java that helps users discover movies based on their preferences including genre, minimum rating, and release year.

## Features

- Filter movies by multiple genres (action, drama, sci-fi, romance)
- Set a minimum rating threshold (0-5)
- Optional year filter (show movies from a specific year onward)
- Sorted recommendations by highest rating first
- Choose how many recommendations to display
- Shows average rating of all recommended movies
- Surprise random movie suggestion feature

## Technologies Used

- Java (JDK 8+)
- Java Collections Framework
- Object-Oriented Programming (OOP)

## How to Run

1. Compile: `javac MovieRecommendation.java`
2. Run: `java MovieRecommendation`
