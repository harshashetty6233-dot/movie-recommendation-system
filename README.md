# 🎬 Movie Recommendation System

A Java console application that recommends movies based on your preferences.

## Features

- Filter by genre (action, drama, sci-fi, romance)
- Filter by minimum rating (0-5 stars)
- Filter by release year
- Shows top recommendations sorted by rating
- Choose how many movies to see
- "Surprise Me" random movie suggestion
- Shows average rating of recommendations

## How to Run

```bash
# Compile
javac Main.java

# Run
java Main

Enter preferred genres: action,drama
Enter minimum rating: 4.5
Filter by minimum year: 2010
